# Introduction

Agentic Headless CMS is a modern, high-performance headless content management system built for developers and content teams.

## What is Agentic Headless CMS?

An open-source headless CMS that combines visual content modeling with instant API delivery. Built with TypeScript, PostgreSQL, and Redis, it allows you to structure, author, and consume content across any frontend without backend friction.

## Key Features

- **Dynamic Schema Builder**: Design custom relational content models visually without writing database migrations
- **Draft & Publish Workflows**: Stage, preview, and publish content changes safely
- **Fast Redis Caching**: Automatic query caching with instant tag-based invalidation
- **Enterprise Security**: Role-based access control (RBAC), TOTP two-factor authentication, and immutable audit logs
- **Multi-Language (i18n)**: Native multi-locale content authoring with default language fallbacks
- **Type-Safe SDKs**: First-party clients for Next.js 15, React, and Node.js

## Why Choose Agentic Headless CMS?

Managing content shouldn't mean wrestling with rigid databases or slow APIs. Agentic Headless CMS provides the right balance of visual control for content creators and developer flexibility for engineering teams.
