The official `@mindfiredigital` SDKs provide typed, production-ready interfaces for querying content, managing media assets, and generating TypeScript definitions across frontend and backend environments.

---

## Available Packages

| Package | Target Environment | Key Features | Installation |
| :--- | :--- | :--- | :--- |
| **`@mindfiredigital/sdk-core`** | Universal (Browser & Node.js) | Base HTTP transport, exponential backoff retries, typed content queries | `npm i @mindfiredigital/sdk-core` |
| **`@mindfiredigital/sdk-nextjs`** | Next.js App Router | React Server Components, server actions, on-demand tag revalidation | `npm i @mindfiredigital/sdk-nextjs @mindfiredigital/sdk-core` |
| **`@mindfiredigital/sdk-react`** | React SPAs (Vite, CRA) | `<CmsProvider>`, `useContentList`, `useContentEntry`, TanStack Query cache | `npm i @mindfiredigital/sdk-react @mindfiredigital/sdk-core @tanstack/react-query` |
| **`@mindfiredigital/sdk-node`** | Node.js Server & Scripts | Filesystem read-stream media uploads, admin automation | `npm i @mindfiredigital/sdk-node @mindfiredigital/sdk-core` |
| **`@mindfiredigital/sdk-codegen`** | CLI / Build Tool | Scans live schemas and outputs static TypeScript interfaces | `npm i -D @mindfiredigital/sdk-codegen` |

---

## Environment Configuration

All client SDKs read connection settings from standard environment variables:

| Variable | Required | Description | Example |
| :--- | :--- | :--- | :--- |
| `CMS_API_URL` | Yes | Backend REST API endpoint | `http://localhost:3000/api/v1` |
| `CMS_API_TOKEN` | Optional | Bearer token for private queries and draft previews | `cms_tok_abcdef123456` |

## Quickstart by Framework

<Tabs groupId="framework">
  <TabItem value="nextjs" label="Next.js" default>

Fetch content directly inside React Server Components (`app/page.tsx`) with zero client bundle overhead:

```tsx
import { getContentList } from '@mindfiredigital/sdk-nextjs';

export default async function BlogPage() {
  const { data: articles } = await getContentList('articles', {
    page: 1,
    pageSize: 10,
    tags: ['articles-feed'],
  });

  return (
    <main>
      <h1>Latest Articles</h1>
      {articles.map((item) => (
        <article key={item.id}>
          <h2>{item.data.title}</h2>
        </article>
      ))}
    </main>
  );
}
```

Wrap your application in `<CmsProvider>` and use TanStack Query hooks:

```tsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
import { CmsProvider, useContentList } from '@mindfiredigital/sdk-react';

const queryClient = new QueryClient();

export function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <CmsProvider baseUrl="http://localhost:3000/api/v1" apiKey="YOUR_API_TOKEN">
        <ArticlesFeed />
      </CmsProvider>
    </QueryClientProvider>
  );
}

function ArticlesFeed() {
  const { data, isLoading } = useContentList('articles');

  if (isLoading) return <p>Loading articles...</p>;
  return <ul>{data?.map((a) => <li key={a.id}>{a.data.title}</li>)}</ul>;
}
```

Use server-side streams for media uploads and background scripts:

```typescript
import { createReadStream } from 'node:fs';
import { createNodeClient } from '@mindfiredigital/sdk-node';

const client = createNodeClient({
  baseUrl: 'http://localhost:3000/api/v1',
  apiToken: process.env.CMS_API_TOKEN,
});

const asset = await client.media.upload({
  file: createReadStream('./whitepaper.pdf'),
  filename: 'whitepaper.pdf',
});

console.log('Uploaded asset ID:', asset.id);
```

Universal isomorphic client for plain JavaScript or TypeScript projects:

```typescript
import { createClient } from '@mindfiredigital/sdk-core';

const client = createClient({
  baseUrl: 'http://localhost:3000/api/v1',
  apiToken: process.env.CMS_API_TOKEN,
});

// Fetch published articles
const { data: articles } = await client.content.find('articles', {
  page: 1,
  limit: 10,
});
```
