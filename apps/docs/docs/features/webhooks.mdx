**Webhooks** send automated HTTP `POST` notifications to external services whenever events occur in Headless CMS. They are commonly used to trigger static site rebuilds, cache revalidations, and Slack or Discord alerts.

---

## Supported Events

| Category | Events | Description |
| :--- | :--- | :--- |
| **Content Lifecycle** | `content.created`, `updated`, `published`, `unpublished`, `deleted` | Triggers when entries are created, modified, published, or removed. |
| **Editorial Workflow** | `workflow.transition`, `review_requested`, `approved`, `changes_requested` | Triggers when content moves across review stages or receives approval. |
| **Media Assets** | `media.uploaded` | Triggers when an asset is uploaded to the Media Library. |

---

## Security & Signatures

Every webhook is assigned a unique secret key. Headless CMS signs every outbound HTTP request using HMAC-SHA256:

- **`x-agentic-signature`**: The computed HMAC-SHA256 hex digest of the raw JSON request body.
- **`x-agentic-event`**: The specific event identifier triggering the delivery.
- Receiving endpoints can verify this signature to guarantee authenticity and prevent tampering.

## Setting Up a Webhook

1. Navigate to **Webhooks** (`/webhooks`) in the dashboard.
2. Click **Create Webhook**.
3. Enter a **Name**, destination **URL**, and select the **Events** to subscribe to.
4. Click **Save**. A secret key is generated automatically.
5. Click **Ping** to test the connection and verify round-trip response latency.

---

## Delivery History & Inspection

Click the history icon on any webhook to open the **Deliveries Drawer**:
- **Status & Latency**: Inspect the exact HTTP response code and execution duration in milliseconds.
- **Payload Inspection**: Review the exact JSON payload sent with the delivery.
- **Timeout Protection**: Outbound requests automatically abort after 5 seconds to prevent hanging requests.
